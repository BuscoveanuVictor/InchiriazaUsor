! ENTRYPOINT si CMD

ENTRYPOINT:
Comanda va fi intotdeauna executata cand pornesti containerul, 
indiferent ce argumente adaugi la docker run.
Este folosita cand vrei ca acel container sa aiba un comportament clar, 
fix (ex: sa ruleze mereu aplicatia ta).

CMD:
Este comanda implicita, dar poate fi suprascrisa 
daca la docker run adaugi alte argumente.
Daca ai si ENTRYPOINT si CMD, argumentele din CMD se adauga la cele din ENTRYPOINT.

! API si REST API
API (Application Programming Interface)	Concept general – orice mecanism care permite două aplicații să comunice între ele.
REST API (REpresentational State Transfer API)	O implementare specifică de API care urmează regulile REST și folosește HTTP pentru a accesa resurse.

! Log vs events
Logs: „Ce a spus aplicația”
Events: „Ce a făcut aplicația”

! Noduri Pods Namespaces cgroups

Namespace	Izolarea logică a resurselor dintr-un cluster Kubernetes.	Izolarea aplicațiilor pentru medii de dezvoltare/testare/producție.
Cgroups	Controlul resurselor (CPU, memorie, I/O) alocate proceselor din containere.	Limitarea utilizării resurselor de către containere (ex: CPU, memorie, I/O).
Pod	Unitate de execuție pentru containere care împart aceleași resurse.	Rularea unui serviciu sau aplicație, cu unul sau mai multe containere în cadrul unui pod.
Node	Mașină fizică sau virtuală care rulează un cluster Kubernetes.	Găzduirea și rularea podurilor pe nodurile de calcul sau control din cluster.
